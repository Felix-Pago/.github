# 🏛️ Felix-Pago Central Standards (.github)

Welcome to the heart of the **Felix-Pago** organization. This repository is used to host organization-wide "Community Health Files." 

### ✨ How this works
GitHub has a "magic" feature: any file placed in this \`.github\` repository acts as a **default template** for every other repository in our organization (private or public).

If a specific project does **not** have its own \`CONTRIBUTING.md\`, \`PULL_REQUEST_TEMPLATE.md\`, or \`SECURITY.md\`, GitHub will automatically use the ones found here.

---

## 📋 What’s inside?

| File | Purpose |
| :--- | :--- |
| [**\`pull_request_template.md\`**](./pull_request_template.md) | Standardizes our PR descriptions to ensure context, testing, and rollback plans are clear. |
| [**\`SECURITY.md\`**](./SECURITY.md) | **Critical:** Defines how to report vulnerabilities via Slack or encrypted email and Bug Bounty details. |
| [**\`GOVERNANCE.md\`**](./GOVERNANCE.md) | Defines roles (Maintainers vs. Admins) and how technical decisions are finalized. |
| [**\`CODE_OF_CONDUCT.md\`**](./CODE_OF_CONDUCT.md) | Outlines our standards for a professional and inclusive work environment. |

---

## 🛡️ Security First
If you discover a security vulnerability, please **do not** report it via a public GitHub issue. 

* **Slack**: Report via the [#secops-reports](https://felix-pago.slack.com/archives/C0940ERM3EZ) channel.
* **Email**: Send to [secops@felixpago.com](mailto:secops@felixpago.com) (PGP encryption available).

Full instructions, including required information for triage and Bug Bounty eligibility, can be found in our [**\`SECURITY.md\`**](./SECURITY.md).

---

## 🛠️ Overriding Defaults
We understand that some projects are special. To override these global standards:
1. Create a \`.github/\` folder inside your specific repository.
2. Add a local version of the file (e.g., \`pull_request_template.md\`).
3. GitHub will now prioritize your **local** file over these organization-wide defaults.

## 🚀 Contributing to Standards
If you think our global standards need an update:
1. Open an issue here in the \`.github\` repo.
2. Submit a PR for the Core Team to review.
3. Once merged, the change will go live for the **entire organization** instantly.
