## Security
  
FelixPago takes the security of our software products and services seriously, which includes all source code repositories managed through our GitHub Enterprise Organizations.  
  
If you believe you have found a security vulnerability in any Felix-owned repository that meets [FelixPago definition of a security vulnerability](https://www.notion.so/felix-tech/Definition-of-a-security-vulnerability-22309747501e805d997fef2761cc139d), please report it to us as described below.  
  
## Reporting Security Issues
  
**Please do not report security vulnerabilities through public GitHub issues.**
  
Instead, please report them to the FelixPago Security Operations Team (SecOps) at our slack channel[secops-reports](https://felix-pago.slack.com/archives/C0940ERM3EZ).  
  
If you prefer to submit without logging in, send an email to [secops@felixpago.com](mailto:felixpago@secops.com).  If possible, encrypt your message with our PGP key; please download it from the [SecOps PGP Key page](https://www.notion.so/felix-tech/SOP-Encrypted-Messages-22309747501e800ea148e4d8e5d624be).  
  
You should receive a response within 24 hours. If for some reason you do not, please follow up via email to ensure we received your original message. 
Additional information can be found at [go/secops](https://www.notion.so/felix-tech/Security-Operations-team-1fa09747501e8038bb61dad6825da0d9) (our notion space). 
  
Please include the requested information listed below (as much as you can provide) to help us better understand the nature and scope of the possible issue:  

  * Type of issue (e.g. buffer overflow, SQL injection, cross-site scripting, etc.)
  * Full paths of source file(s) related to the manifestation of the issue
  * The location of the affected source code (tag/branch/commit or direct URL)
  * Any special configuration required to reproduce the issue
  * Step-by-step instructions to reproduce the issue
  * Proof-of-concept or exploit code (if possible)
  * Impact of the issue, including how an attacker might exploit the issue
  
This information will help us triage your report more quickly.  
  
If you are reporting for a bug bounty, more complete reports can contribute to a higher bounty award. Please visit our [FelixPago Bug Bounty Program](https://www.felixpago.com/en/bug-bounty-program) page for more details about our active programs.  
  
## Preferred Languages
  
We prefer all communications to be in English.  
  
## Policy
  
FelixPago follows the principle of [FelixPago Vulnerability Disclosure Policy](https://www.felixpago.com/en/vulnerability-disclosure-policy).
